AUDIT MODE Vendor Audit Workflow

An 8-stage audit workflow that enforces itself.

Vendor audits today run on emails, shared folders, and version chaos. PIQC replaces that with a gated 8-stage workflow — from intake through final export — where nothing advances until the right approvals are in place.

INTAKE→ ENRICH→ QUESTIONNAIRE→ RISK→ DRAFTING→ CONDUCT→ REPORT→ EXPORT

  • Questionnaire with vendor response tracking

    ANSWERED / PARTIAL / DEFERRED / UNANSWERED status on every item. Amendment alerts when protocol changes mid-audit.

  • Risk-scored findings with criticality derivation

    CRITICAL / HIGH / MODERATE / LOW with DATA_INTEGRITY and PATIENT_SAFETY impact surfaces.

  • Gated report generation

    Confirmation letter, agenda, checklist, and final export — each requiring explicit approval before the next gate opens.
